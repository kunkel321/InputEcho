# InputEcho
- Evolved from On-Screen Keyboard, which was based on the original by Jon Lehnemann, et al.
- Converted to AHK v2 by kunkel321 using Claude AI. 
- Code also reworked with ChatGPT.
- Version date: (updated in code)  

8-15-2026 Name was changed from "OnScreenKeyboard" to "InputEcho" and support for Mouse-Click Highlights was added.

- Ctrl+Alt+K show/hide keyboard; Alt+arrow / Alt+wheel transparency
- Ctrl+Alt+M show/hide mouse click highlights
- This script creates a mock keyboard at the bottom of your screen that shows the keys you are pressing in real time. It also shows your mouse-clicks.  The original KB app by Jon was made to help with learning to touch-type by not having to look at the physical keyboard. It might also be useful as an on-screen display for screencasts. The mouse-click highlighting is intended for screencasts.  Corresponding "mouse buttons" on the keyboard correspond to the click highlights. The keyboard and mouse highlight appearances can be customized via control panels that are accessed via the system tray menu. Control tooltips on the panels use Musut Akcan's CtrlToolTips.ahk class.
